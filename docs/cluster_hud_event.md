# 외장 9.2인치 HUD: 중앙 상단 이벤트 표시 (2026-11-24)

TURZX 외장 HUD(`ClusterHud` 1·2)의 기본 화면(앰비언트)에 콤마의 현재 경고를 띄운다(`ClusterHudDisplayMode` 2~6). 두 줄짜리 경고는 두 줄 다 띄운다.
화면 표시만 바꾸며, 경고 판단·소리·주행 제어는 그대로다.

## 설정: 외부 HUD 표시 모드 (`ClusterHudDisplayMode`, 0~6, 기본 1)

당근웹 → 설정 → 화면 → 외부 HUD → 기본 항목에서 고른다. 바꾸면 1초 안에 적용되고 재부팅은 필요 없다.

| 값 | 화면 |
|---|---|
| 0 | 끄기. 외부 HUD 화면이 꺼진다. 시동이 꺼졌을 때와 같은 방식으로, HUD 프로세스가 내려가고 자동 실행기가 패널을 어둡게 둔다. 다시 1 이상으로 바꾸면 몇 초 안에 켜진다. |
| 1 | 기본 화면(이벤트 표시 전 그대로) |
| 2 | 기본 화면 + 콤마 이벤트(아래 "보이는 것") |
| 3~6 | 나중에 만들 화면용 자리. 지금은 2와 같다. |

- `ClusterHud`(0 끄기 / 1 9.2인치 / 2 12.3인치)는 그대로다. HUD를 쓸지와 패널 종류는 여전히 `ClusterHud`로 정한다.
- 기본값을 1로 둔 이유: 이 설정이 생기기 전 화면과 같게 하려고. EV6에서 이벤트를 보려면 2로 바꾼다.
- 값이 없거나 읽지 못하면 1로 본다. 새 설정 키를 모르는 예전 params 빌드도 1로 동작한다.

## 보이는 것

- 위치: 상단 줄(제한속도·기어·설정속도·차로 유지 아이콘)과 왼쪽 큰 속도 사이의 빈 가운데. 칸이나 테두리 없이 글자만 띄운다.
  - 글자는 x 575~1355 사이에만 그린다. 왼쪽 끝은 세 자리 속도 숫자(x 534까지)에서 띄웠고, 오른쪽 끝은 폰 음악 칸(x 1379) 앞이다.
  - 짧은 문구는 상단 줄 가운데(x 905)에 맞춘다. 거기서 영역을 벗어날 만큼 넓은 문구만 필요한 만큼 오른쪽으로 민다.
- 내용:
  - 첫 줄: `selfdriveState`의 `alertText1`. 글자 크기 58이고, 단계 색으로 칠한다.
  - 둘째 줄: `alertText2`가 있으면 첫 줄 아래에 크기 38의 회색으로 띄운다. 두 줄이면 첫 줄이 조금 올라간다.
  - 첫 줄이 비어 있으면 둘째 줄을 첫 줄로 올린다.
  - 경고가 없을 때(`alertSize` none)는 아무것도 뜨지 않는다.
  - 긴 줄은 최대 폭(780)에 맞춰 글자를 줄인다. 첫 줄은 58에서 36까지, 둘째 줄은 첫 줄 크기의 0.66배(최대 38)에서 26까지 줄인다.
    그보다 더 길 때만 끝을 `...`로 자른다. 지금 EV6 경고 163개 중 `...`로 잘리는 것은 없다.
  - 두 줄 모두 가운데 정렬이다.
- 색(첫 줄 글자와 뒤의 은은한 빛):
  - 정보(normal): 흰 글자, 파란 빛
  - 주의(userPrompt, 콤마가 운전자에게 무언가 요구): 주황 글자, 주황 빛
  - 위급(critical, 즉시 조작): 빨간 글자, 빨간 빛. 빛이 은은하게 깜박인다.
  - 빛은 글자 뒤에 가로로 긴 타원으로 옅게 번진다.
- 움직임:
  - 뜰 때 0.18초 동안 나타나며 살짝 내려온다.
  - 경고가 끝나도 0.5초 더 두었다가 0.35초 동안 사라진다. 한 프레임 끊긴 경고는 깜박이지 않는다.
  - 글자가 바뀌면 바로 바꾼다. 단계(색)가 바뀌거나 사라지는 중에 새 경고가 오면 다시 나타나는 효과를 준다.
    같은 경고 안에서 글자만 바뀔 때(예: 캘리브레이션 4% → 5%)는 깜박이지 않고 제자리에서 바뀐다.
  - eGPU를 쓰면 본체 출력이 5 FPS라 움직임은 한두 프레임으로 짧게 보인다.
- 디자인 이력: 처음에는 점이 달린 색 테두리 칸이었다. 사용자가 점을 빼라고 했고, 칸도 디자인이 별로라고 했다.
  그래서 세 가지 시안(글자+빛, 가로 띠, 어두운 카드)을 렌더로 비교했고, 사용자가 글자+빛(A)을 골랐다.

## 한글 글꼴

이벤트 글자는 Pretendard Bold에서 필요한 글자만 불러온다(폰 음악 제목과 따로 캐시해 서로 매 프레임 다시 불러오지 않게 함).
큰 글자 몇 개만 불러오면 raylib이 글자판(아틀라스)을 작게 잡아 마지막 글자가 빠진다
("전방 주의"에서 "주", "브레이크!"에서 "크"가 빠졌음). 그래서 늘 ASCII 글자를 함께 불러오고,
불러온 뒤에도 빠진 글자가 있으면 다른 크기(96 → 128 → 72)로 다시 불러온다.

폰 음악 제목 글꼴(`_phone_media_font_for`)도 같은 방식(160 크기, 글자만)이라 같은 문제가 생길 수 있다. 이번에는 고치지 않았다.

## 검증한 것과 못 한 것

- 맥 테스트: 외장 화면 테스트 28개(이벤트 10개, 표시 모드 5개 포함)와 젯슨 패널 출력 테스트 9개가 통과했다.
- 표시 모드: 모드 1·2·4로 실제 로그를 렌더해 1에서는 이벤트가 안 뜨고 2·4에서는 뜨는 것을 확인했다.
  모드 0은 자동 실행기(`_hud_output_allowed`)와 메인(`ClusterHudOutputGateParamReader`) 둘 다 출력을 막는 것을 가짜 Params로 확인했다.
  당근웹 설정 목록에서 외부 HUD → 기본 항목에 들어가는 것을 서버 코드로 확인했다(브라우저 화면은 안 봄).
- 맥 렌더: 실제 주행 로그로, 9.2인치 패널에 보내는 프레임(1920×462)을 그대로 받아 확인했다.
  - 트래버스 `0000023f--ff2039c594--3`: "전방 주의"(주의), "정지합니다"(정보), "조향 보조 꺼짐"(주의)
  - 말리부 `0000001d--c1e04a331d--15`: "브레이크! / 추돌 위험"(위급)과 사라지는 모습
  - 말리부 `00000043--454fc2ef42--18`: 한 줄짜리 긴 문구 "11 km/h 이상의 속도에서 조향 됩니다"
  - 경고 정의의 문구를 강제로 넣어 렌더: 자주 보는 18개와 예전에 잘리던 7개(속도 118 km/h로 고정해 숫자와 안 겹치는지 확인)
  - "전방 주의", "정지합니다", "끼어드는 차량 감지" 등 일부는 트래버스·말리부(WIP-FR) 로그의 당근 전용 경고라 EV6에서는 뜨지 않는다.
- 못 함: EV6 실기기와 실제 패널 화면. 기기 GPU(GLES)와 하드웨어 H264 경로로는 확인하지 않았다.
